# Kitchen CAD

Браузерный параметрический конструктор кухни с приоритетом мобильного интерфейса. Одна модель данных используется для визуализации, размеров, предварительной деталировки и экспорта.

**Live:** https://den-2020.github.io/kitchen-cad/

> Текущий статус: развивающийся прототип, а не сертифицированная CAD/CAM-система. Перед производством размеры, вырезы, кромку, крепёж и зазоры необходимо проверить с конкретным цехом и инструкциями техники/фурнитуры.

## Реализовано

- полноэкранный mobile-first интерфейс и desktop-режим;
- RU / EN и светлая / тёмная тема;
- редактируемые размеры комнаты;
- выбор модуля и отдельных объектов прямо на сцене;
- перемещение выбранного модуля по комнате;
- вращение 3D-сцены по двум осям, масштаб, виды спереди и сверху;
- нижние, навесные шкафы, шкаф под **раковину**, стиральная и посудомоечная машины, духовка, холодильник;
- размеры Ш × В × Г, положение X/Z, материал корпуса/фасада;
- 1–4 створки или авто-режим;
- свес фасада сверху/снизу/слева/справа — фасад может быть больше корпуса;
- плоские, рамочные, стеклянные и реечные фасады (пока визуальная модель);
- варианты ручек и ножек;
- отдельная настраиваемая столешница: авто/ручная длина, глубина, толщина, смещение, декор;
- раковина и варочная поверхность как встраиваемые элементы, привязанные к выбранному нижнему шкафу;
- предупреждения и красная подсветка при выходе за комнату, пересечении модулей, неверном перекрытии столешницей или слишком большом встраиваемом элементе;
- размеры: основные / выбранного элемента / все детали;
- разобранный вид с ползунком расстояния разнесения;
- предварительная деталировка и CSV;
- сохранение проекта JSON;
- экспорт PNG и одностраничного PDF-чертежа с текущим видом и перечнем деталей;
- автоматические тесты расчётного ядра и GitHub Pages deploy.

## Важные ограничения

- Раковина и варочная поверхность сейчас создают параметрический габарит/контур выреза. Для производства нужен точный шаблон конкретной модели производителя.
- Стили рамочных/стеклянных/реечных фасадов пока меняют визуализацию; технологическая фрезеровка, стекло и профиль ещё не входят в спецификацию.
- Техника пока параметрическая. Следующий визуальный слой — оптимизированные GLB/GLTF-модели с сохранением наших точных габаритов.
- PDF сейчас является одностраничным обзорным чертежом. Полный производственный PDF с отдельными листами деталей и раскроем — отдельный следующий этап.
- Пока нет схем сверления Blum/Hettich, автоматической оптимизации листового раскроя, DXF и инженерного расчёта каменной столешницы.

## Архитектурный принцип

```text
Project JSON
   ↓
validate / layout
   ↓
buildProject
   ├── scene objects
   ├── Parts[]
   ├── fixtures
   ├── issues / warnings
   └── countertop
          ↓
       UI / CSV / PNG / PDF
```

Расчётные формулы находятся в `src/core`, а не в UI. Поэтому смена темы, 3D-модели техники или интерфейса не должна менять производственные размеры.

## Разработка на Windows 11

Нужен Node.js 22.16+.

```powershell
npm test
npm run build
```

GitHub Pages публикуется workflow-файлом `.github/workflows/pages.yml` после push в `main`.

## 3D assets

Для будущих реалистичных моделей предпочтительны ассеты с понятной лицензией (в первую очередь CC0), например Quaternius / Kenney / Poly Haven. Перед включением модели должны быть оптимизированы по полигонам, текстурам и размеру загрузки для мобильных устройств.
